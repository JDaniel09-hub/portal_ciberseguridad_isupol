Arquitectura y Estructura de Computadores

Arquitectura del sistema computacional

La computadora procesa información mediante una organización de componentes físicos y lógicos que separan, coordinan y ejecutan el flujo de instrucciones.

01

CPU: Unidad Central de Procesamiento

La CPU coordina el procesamiento de datos y la ejecución de instrucciones mediante componentes especializados.

  • ALU: ejecuta operaciones aritméticas y lógicas.
  • UC: interpreta instrucciones y organiza el flujo de datos.
  • Registros: almacenan datos temporales y direcciones.
02

Ciclo de instrucción

Las instrucciones se leen, decodifican y ejecutan en un flujo cíclico controlado por la unidad de control.

FETCH → DECODE → EXECUTE
Fetch Decode Execute
03

Fundamentos de Redes de Comunicaciones

Redes informáticas y conectividad

Una red informática permite la interconexión de equipos para compartir recursos, datos y servicios de forma organizada y segura.

RED-01

Definición de red

Una red informática es un conjunto de dispositivos interconectados mediante protocolos y medios de transmisión que permiten intercambio de información.

RED-02

Importancia

Las redes permiten la comunicación entre equipos, la colaboración institucional, el acceso a servicios y la gestión centralizada de información.

RED-03

Dirección IP y Dirección MAC

PROTOCOLO TCP/IP
DIRECCIÓN IP

Qué es

Identifica una interfaz de red dentro de una red lógica o de Internet.

Características
  • Se asigna a nodos.
  • Puede ser pública o privada.
  • Soporta enrutamiento.
DIRECCIÓN MAC

Qué es

Identifica físicamente una tarjeta de red en la capa de enlace de datos.

Características
  • Es un identificador fijo.
  • Se usa dentro de una LAN.
  • Se relaciona con el hardware.

Topologías físicas

Infraestructura
✦

Estrella

Todos los nodos conectados a un punto central como switch o hub.

  • Ventaja: fácil administración.
  • Desventaja: falla central afecta red.
◎

Anillo

Los equipos están conectados en secuencia, formando un camino circular.

  • Ventaja: estructura ordenada.
  • Desventaja: alta dependencia de cada enlace.
▥

Bus

Todos los nodos comparten un mismo medio de transmisión.

  • Ventaja: simple y económico.
  • Desventaja: colisiones y falla de canal.
Investigación de Ciberdelitos

Aplicación en informática forense

El conocimiento técnico de la computadora y las redes es esencial para reconstruir eventos, recopilar evidencia y analizar incidentes.

Memoria RAM

La RAM permite obtener evidencia volátil como procesos activos, conexiones abiertas, archivos temporales y datos de sesión.

Registros del procesador

Los registros ayudan a comprender el flujo de la ejecución de instrucciones y el contexto del procesamiento.

Tráfico de red

El tráfico permite analizar conexiones sospechosas, protocolos, mensajes, puertos y patrones de comunicación.

01

Extracción de evidencia digital

Se identifican y preservan artefactos relevantes de memoria, archivos, registros y tráfico.

02

Análisis forense

Se correlacionan datos para reconstruir cronologías y establecer relaciones entre eventos.

03

Investigación de incidentes

Se evalúa el alcance, la causa probable y los mecanismos utilizados en la actividad sospechosa.
